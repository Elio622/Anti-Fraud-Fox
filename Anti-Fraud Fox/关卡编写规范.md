# 《反诈狐》关卡编写规范

> 本规范以「关卡 1（免费皮肤诈骗）」为准，后续关卡照此编写。当前第 1~15 关已全部完成。
> 有任何约定变更，请同步更新本文件。
>
> **例外**：第 15 关（最终关）不采用标准「三轮三选」模板，而是「连环五幕 + 计分」结构，详见第五节末尾「第 15 关特殊结构」。

---

## 一、项目概览

- 引擎：Ren'Py 8.5.3，分辨率 **1280 × 720**。
- 题材：面向中小学生的反诈宣传剧情游戏，动物卡通画风。
- 玩法：15 关，每关「前置剧情 → 多轮三选一抉择」，走向反诈成功 / 被骗的不同结局。
- **正确选项位置刻意打散**：每关每个菜单中，通往 3 星结局的正确选项位置不固定（第 1/2/3 位均有分布），避免玩家「无脑选第一项」。新写关卡时也请遵守此约定。
- 解锁：**顺序解锁**，通关本关自动解锁下一关。
- 星级：**3 星制**（1 星 / 2 星 / 3 星）。

## 二、文件结构

| 文件 | 作用 |

| `game/gui.rpy` | 界面颜色、字号、字体、布局 |
| `game/images/` | 所有图片素材 |
| `game/audio/` | 音频素材目录（当前暂无音频文件，目录内有 `说明.md`） |
| `game/tl/schinese/` | 引擎系统提示的简体中文官方翻译（仅 `common.rpy`，勿手改） |

> 但记得补英文翻译（见第五节关键点 7）：跑 `translate english` 生成 `game/tl/english/chNN.rpy` 后填译文。

## 三、角色与表情规范

### 3.1 角色清单（`script.rpy` 已定义，勿重复定义）

| 变量 | 显示名 | image tag | 用途 |
|------|--------|-----------|------|
| `mc` | 阿狐 | `mc` | 主人公小狐狸说话 |
| `think` | 阿狐 | `mc` | 主人公内心独白（自动加括号） |
| `fraud` | 客服 | `fraud` | 诈骗分子（浣熊） |
| `mom` | 妈妈 | `mom` | 小狐狸母亲 |
| `dad` | 爸爸 | `dad` | 小狐狸父亲 |
| `teacher` | 老师 | `teacher` | 猫头鹰老师 |
| `police` | 反诈警察 | `police` | 狗狗警长 |
| `rabbit` | 小兔 | `rabbit` | 阿狐的同学（ch03 被冒充的好友）；Character 定义在 `ch03.rpy`，7 种表情立绘已注册到 `script.rpy` |
| `n` | （无） | — | 旁白，不显示名字 |

**本关专属角色（冒充类骗局用）**：骗子冒充「同学 / 老师 / 警官」等身份说话时，名字框不能再显示「客服」。做法是在本关 `chNN.rpy` 里定义一个临时角色，**复用 `fraud` 的立绘 tag**（不用新图）：

```renpy
# game/ch03.rpy 示例：骗子盗号后冒充的同学「小兔」
define rabbit = Character("小兔", who_color="#ffffff", who_outlines=[(2, "#000000", 0, 0)], image="fraud")
```

已采用的先例：ch09 `l9_cop`（李警官）、ch10 `xiaoyu`（小雨）、ch15 `l15_teacher`（王老师）/ `l15_cop`（李警官）；ch03 的「小兔」早期复用 `fraud` 立绘，现已生成独立表情立绘 `rabbit_*.png`（7 表情 + 底图，FSRCNN 4x 超分）并注册到 `script.rpy`，角色定义改为 `image="rabbit"`。定义时注意：
- 全局变量名不要与其他关重复；
- 角色显示名需在 `tl/english/chNN.rpy` 的 `strings` 块补英文（`translate english` 不会自动收集）；
- **`strings` 块里的 `old` 条目全局只能出现一次**——两关复用同一人名时（如 ch09、ch15 都有「李警官」），翻译条目只写在最先加载的关卡文件里，重复定义不会在 lint 报错，但游戏启动时会抛 `A translation for "..." already exists` 异常直接崩溃。

**AI 换脸 / 语音冒充真人**：AI 冒充「爸爸」「妈妈」的桥段，直接借用其真实角色（`dad` / `mom`）呈现以假乱真的画面声音——名字框显示「爸爸/妈妈」正是受害者看到的效果（先例：ch14 假「爸爸」视频、ch15 假「妈妈」语音），无需新角色和新图；揭穿后的真本人再以旁白或同角色正常表情出场。

### 3.2 表情属性（说话时直接写在角色名后）

表情属性共 7 种：`normal`（正常）、`serious`（严肃）、`laugh`（大笑）、`worried`（担心）、`sad`（沮丧）、`confused`（疑惑）、`suspicious`（怀疑）。

**注意：不是每个角色都有全部 7 种表情。** 当前各角色已注册的立绘（以 `script.rpy` 为准）：

| 角色 | 可用表情 | 缺少的 |
|------|----------|--------|
| `mc` 阿狐 | normal、serious、laugh、worried、sad、confused | suspicious |
| `fraud` 客服 | normal、serious、laugh、worried、sad、suspicious | confused |
| `mom` 妈妈 | normal、serious、laugh、worried、sad、confused | suspicious |
| `dad` 爸爸 | normal、serious、laugh、worried、sad、confused | suspicious |
| `rabbit` 小兔 | normal、serious、laugh、worried、sad、confused、suspicious | （无，7 种齐全） |
| `teacher` 老师 | normal、serious、laugh、worried、sad、suspicious | confused |
| `police` 反诈警察 | normal、serious、laugh、sad、suspicious、confused | worried |

写剧本前对照上表；要用到「缺少的」表情时，先按第七节补齐立绘并在 `script.rpy` 注册 `image side xxx <表情>`。

中文素材名 ↔ 英文属性的对应关系：

| 中文 | 英文属性 | 中文 | 英文属性 |
|------|----------|------|----------|
| 正常 | `normal` | 严肃 | `serious` |
| 大笑 | `laugh` | 担心 | `worried` |
| 沮丧 | `sad` | 疑惑 | `confused` |
| 怀疑 | `suspicious` | | |

### 3.3 三种说话方式

```renpy
# 旁白（无名字、无立绘）
n "周五的傍晚，作业全部完成。"

# 主人公说话（左侧显示阿狐表情立绘）
mc serious "天下没有免费的皮肤。"

# 主人公内心独白（左侧阿狐立绘 + 文字加括号）
think worried "虽然很想要皮肤，但总觉得不太对劲。"
```

> 注意：给角色加表情时，该角色的 `Character` 定义必须带 `image="tag"` 参数（`script.rpy` 已配好）。
> 例如 `fraud laugh "..."` 会显示「客服」的笑脸立绘。

## 四、图片规范（重要）

### 4.1 立绘（对话框左侧头像）

- 格式：**透明底 RGBA PNG**，无白底、无水印、无噪点。
- 命名：`game/images/{角色tag}_{表情}.png`，例如 `mom_serious.png`、`police_laugh.png`。
- **统一高度**（关键约定）：
  - 大多数角色立绘统一高度 **1783 px**（以主人公阿狐为标准），保持宽高比缩放。
  - 例外：`fraud`（诈骗犯）、`mom`（妈妈）缩为 **1426 px**（用户已手动调小）。
  - 后续新增表情图，抠图后按角色对号入座缩放高度。
- 显示由 `script.rpy` 里的 `side_portrait` transform 统一控制：

```renpy
transform side_portrait:
    xalign 0.0      # 靠左
    yalign 1.0      # 底部对齐
    xoffset 100     # 相对左边缘的偏移
    yoffset -40     # 相对底部的偏移
    zoom 0.085      # 缩放倍数
```

**屏显宽度约束（防遮挡正文）**：对话正文从 x=268 开始，立绘 xoffset=100，因此立绘屏显宽度必须 ≤156px（右缘 ≤256）。按 0.085 缩放即**原图宽度 ≤1835px**；超宽的立绘（如小兔垂耳 2265px、老师翅膀 2175px）在 `script.rpy` 注册时用 `Transform(..., zoom=系数)` 附加缩小（小兔 0.81、老师 0.70），把屏显宽度收窄到 156px 以内，否则会遮挡对话文本。注意：名字框从 x=240 起，若立绘可见像素铺满画布右缘（如老师展开的翅膀），还需额外收紧（老师由 0.84 收紧到 0.70，屏显约 129px、右缘 x≈229），避免压住名字框。

### 4.2 背景 / 场景图

- 尺寸：**1280 × 720**（用 `Transform(..., xsize=1280, ysize=720)` 强制铺满）。
- 命名：关卡内用 `l{N}_{场景}`，例如 `l1_msg`、`l1_claim`；通用背景用 `bg_xxx`。

### 4.3 结算图

- 通关图：`clear1.png`（1 星）、`clear2.png`（2 星）、`clear3.png`（3 星），1280 × 720。
- 失败图：`fail.png`，1280 × 720。

## 五、关卡脚本标准模板

```renpy
# game/chNN.rpy
define lN_tip = "本关防骗口诀（一句顺口溜）"

label chN:

    # === 前置剧情 ===
    scene lN_场景名
    n "旁白……"
    think 表情 "（内心独白）……"
    mc 表情 "说话……"

    # === 第一轮抉择 ===
    fraud 表情 "骗子的话……"

    menu:
        "选项A（理智避险）":
            jump chN_A
        "选项B（好奇试探）":
            jump chN_B
        "选项C（主动上钩）":
            jump chN_C

# ============ 分支 A：理智避险（满分） ============
label chN_A:
    scene lN_场景名
    think serious "……"
    mc serious "……"
    police laugh "……"

    $ clear_chapter(N, 3)
    $ quick_menu = False
    call screen level_clear(N, 3, lN_tip)
    $ quick_menu = True
    jump select_level

# ============ 分支 B：好奇试探（进入第二轮） ============
label chN_B:
    scene lN_场景名
    mc confused "……"
    fraud laugh "……"

    menu:
        "选项B1（求助家长，满分）":
            jump chN_B1
        "选项B2（及时止损，2星）":
            jump chN_B2
        "选项B3（轻微泄露，1星）":
            jump chN_B3

label chN_B1:
    # 满分结局
    $ clear_chapter(N, 3)
    $ quick_menu = False
    call screen level_clear(N, 3, lN_tip)
    $ quick_menu = True
    jump select_level

label chN_B2:
    # 2 星结局
    $ clear_chapter(N, 2)
    $ quick_menu = False
    call screen level_clear(N, 2, lN_tip)
    $ quick_menu = True
    jump select_level

label chN_B3:
    # 1 星结局
    $ clear_chapter(N, 1)
    $ quick_menu = False
    call screen level_clear(N, 1, lN_tip)
    $ quick_menu = True
    jump select_level

# ============ 分支 C：主动上钩（进入第三轮） ============
label chN_C:
    scene lN_场景名
    mc laugh "……"
    fraud laugh "……"

    menu:
        "选项C1（临危醒悟，满分）":
            jump chN_C1
        "选项C2（侥幸试探，1星）":
            jump chN_C2
        "选项C3（完全轻信，被骗）":
            jump chN_C3

label chN_C1:
    $ clear_chapter(N, 3)
    $ quick_menu = False
    call screen level_clear(N, 3, lN_tip)
    $ quick_menu = True
    jump select_level

label chN_C2:
    $ clear_chapter(N, 1)
    $ quick_menu = False
    call screen level_clear(N, 1, lN_tip)
    $ quick_menu = True
    jump select_level

label chN_C3:
    # 被骗结局
    $ quick_menu = False
    call screen level_fail(N, lN_tip)
    $ quick_menu = True
    if _return == "retry":
        $ _history_list = []
        jump chN
    else:
        jump select_level
```

### 关键点

0. **台词里的字面百分号必须写成 `%%`**：Ren'Py 对含 `%` 的台词做 `%` 格式化，写 `100%`、`30%` 会在播放到该句时抛 `ValueError: unsupported format character` 直接崩溃（lint 只给警告、不报错，务必自律）。中文剧本和 `tl/english/` 英文译文都要遵守。
1. `define lN_tip` 的 `N` 必须换成具体关卡号（如 `l2_tip`）。
2. `clear_chapter(N, 星级)` 记录最佳星级并解锁下一关；星级取 `1` / `2` / `3`。
3. `level_clear(章节, 星级, tip)` 显示对应星级的通关图；`level_fail(章节, tip)` 显示失败图。`tip`（防骗口诀）参数目前保留但结算界面不单独渲染，剧本里照模板传 `lN_tip` 即可。
4. 通关/失败前后都要 `$ quick_menu = False` → `call screen` → `$ quick_menu = True`，避免结算界面出现快进按钮。
5. 所有结局最后 `jump select_level` 回到选关；被骗结局按 `_return` 决定重试或返回。
6. **对话历史重置**：从选关界面进入关卡时，`select_level` 会统一清空 `_history_list`（对话历史）；
   但被骗结局的「重新挑战」分支是直接 `jump chN`，不经过选关，因此必须自带一行 `$ _history_list = []`（见模板）。
7. **语言约定**：游戏提供简体中文 / English 双语，在设置界面切换，默认简体中文。
   - 引擎系统提示的翻译在 `game/tl/schinese/common.rpy`（官方翻译，勿手改）与 `game/tl/english/common.rpy`。
   - 界面文案一律用 `_()` 包裹（动态文本如关卡名用 `__()`）；剧情对话的英文在 `game/tl/english/` 的 `translate english` 块中。第 1、3~15 关的英文翻译已完成（`game/tl/english/chNN.rpy`）。
   - 新增一关后运行 `renpy.exe 项目目录 translate english` 生成 `game/tl/english/chNN.rpy` 翻译骨架，再补填英文译文；不补的话英文模式下该关会直接显示中文原文。

## 六、星级与解锁逻辑

- 星级只在 `clear_chapter` 里升级（只升不降），`persistent.stars` 保存每关最佳成绩。
- 通关任一结局（哪怕 1 星）即解锁下一关：`persistent.unlocked` 递增。
- 被骗结局不解锁下一关、不计星。

### 第 15 关特殊结构（最终关）

第 15 关不遵循「三轮三选」模板，而是**连环五幕 + 计分**结构，难度与剧情厚度均为全游戏最高：

- **五幕**：前置剧情（家庭暗号伏笔、小兔开场）→ 第一幕 开局双线（礼包 + 假王老师）→ 第二幕 AI 换脸视频通话 → 第三幕 假警察 + 假「安全防护」APP → 第四幕 三线收网 + 家庭暗号终局 → 结局。
- **计分制星级**：`l15_score` 记录正确抉择数（0~4，四幕各 1 分），最终按分数定星级：4 分 → 3 星、2~3 分 → 2 星、0~1 分 → 1 星。第四幕选「报验证码」直接进入被骗结局（`level_fail` + 重试）。
- **状态影响剧情与结局**：`l15_leak`（点钓鱼链接泄露账号密码）、`l15_paid`（向「王老师」转账）、`l15_screen`（开屏幕共享）、`l15_knows`（第二幕追问细节后确证「王老师」是假货）四个标志会改变后续剧情与结局叙述（如账号被洗、钱款损失、骗子实时看到验证码等），前期失误的代价在结局里逐条兑现。`l15_knows` 还会用「菜单项条件」切换第三幕第三个选项：确证假货的玩家看到的是「将计就计装APP取证」的过度自信陷阱，而非「轻信装APP」。
- 结局复用 `ch15_end3 / ch15_end2 / ch15_end1` 三个共享结局 label，内部用 `if l15_leak` 等条件插入对应叙述。
- **正确选项位置刻意打散**（避免「永远选第一项」）：四幕正确项分别在第 2、3、2、1 位。

## 七、素材位置与抠图方法

- 原始素材：开发机上仓库同级的 `素材/` 目录（不上传 GitHub，见 `.gitignore`），按角色分目录（小狐狸主角 / 母亲 / 父亲 / 老师 / 警察 / 诈骗犯）。
- 抠图（白底转透明 + 去水印）用 Python（PIL + numpy + scipy）：
  1. 计算每个像素与纯白 (255,255,255) 的距离，`距离 < 28` 判为背景候选；
  2. `scipy.ndimage.label` 做 8 连通分量，删除「与图片边框相连」的分量（背景）；
  3. 对剩余前景再做一次连通分量，**只保留最大的分量**（去掉右下角水印 / 噪点）；
  4. 按角色统一高度缩放（多数 1783，fraud/mom 1426），保持宽高比（LANCZOS）。
- 扣好的透明图放 `game/images/{角色}_{表情}.png`。

## 八、验证流程

每改完脚本，跑一遍 lint 再启动游戏：

```bash
renpy.exe "项目目录" lint
renpy.exe "项目目录"
```

- lint 无报错 → 语法/图片引用正确。
- 启动后进关卡，重点检查：表情是否正常显示、立绘是否透明无白底、结算图是否对号。
